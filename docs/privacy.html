Privacy Policy

Effective date: October 21, 2026

Live Streamer is a personal tool by Blue Plaid Racing (Robert Neville), used only by Robert to manage his own YouTube channel.

What it accesses

Live Streamer uses the YouTube Data API with the youtube and youtube.upload scopes to schedule live broadcasts and upload thumbnails on Robert's own channel.

How data is stored

OAuth tokens are stored privately on Robert's own machine. No data is shared or sold, and no data is collected from anyone else.

YouTube API Services

Live Streamer uses YouTube API Services. By using Live Streamer, you agree to be bound by the YouTube Terms of Service. Your use is also subject to the Google Privacy Policy.

Data from others

Live Streamer collects no data from anyone other than Robert.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
